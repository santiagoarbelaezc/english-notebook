<h1 align="center">📓 English Notebook</h1>

<h3 align="center">🎯 Aplicación tipo Notion para aprendizaje de inglés</h3>

<p align="center">
  Plataforma React + TypeScript para organizar y practicar inglés de forma interactiva.<br>
  Interfaz intuitiva similar a Notion con múltiples secciones de aprendizaje.
</p>

---

## 🎯 **Descripción**

**English Notebook** es una aplicación web moderna desarrollada en **React con TypeScript** que funciona como un cuaderno digital para el aprendizaje de inglés. Con una interfaz similar a Notion, permite organizar todo el contenido de estudio en un solo lugar de forma estructurada y accesible.

---

##  **PENDIENTE MEJORAS EN LA INTERFAZ**
componente de conversaciones (implemntacion de groq)
componente de profile

---

## ✨ **Características Principales**

### **📚 Secciones de Estudio**
- **📖 Verbos Irregulares:** Lista organizada y práctica
- **🔤 Vocabulario:** Palabras nuevas por categorías
- **💬 Conversaciones:** Diálogos y prácticas de speaking
- **✨ Frases Diarias:** Expresiones útiles para aprender
- **✅ Compromisos:** Metas y objetivos de estudio

### **👤 Sistema de Usuario**
- **🔐 Login/Registro** seguro
- **👤 Perfil personalizado** 
- **💾 Guardado automático** de progreso
- **🌙 Modo claro/oscuro**

### **🎨 Interfaz Intuitiva**
- **Drag & Drop** para organizar contenido
- **Editor enriquecido** tipo Notion
- **Búsqueda rápida** en todo el contenido
- **Vistas personalizables** (lista, tarjetas, tabla)

1. **📝 Crea tu cuenta** y personaliza tu perfil
2. **➕ Añade contenido** en las diferentes secciones
3. **🗂️ Organiza** con drag & drop
4. **🔍 Busca y repasa** cuando necesites
5. **📈 Sigue tu progreso** en el dashboard
